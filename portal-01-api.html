Create an order

Method Description

In order to perform a payment via Paynet API, the payment must first be registered in the Paynet system. The Create order method is used to create (register) a new payment order by transmitting the required payment details from the Partner’s system to Paynet. Upon successful registration, Paynet generates and returns a unique payment identifier (Payment ID). This Payment ID is then used to redirect the customer to the Paynet payment page, where the user can review, confirm, and complete the payment. In this model, direct server-to-server communication between the Partner and Paynet is required. Data signing is not mandatory, as authentication is handled via an authorization token.

Request Type and URL

Name URL:
https://ecom-api-test.paynet.md/api/order

Parameters - Description

OrderintegerbodyRequired

The unique identifier for the order.

SaleAreaCodestringbodyRequired

The code representing the sale area or merchant location.

LinkUrlSuccessstringbodyRequired

The URL to redirect to upon a successful payment.

LinkUrlCancelstringbodyRequired

The URL to redirect to if the payment is canceled.

CardLinkHashstringbodyOptional

(Optional) Linked-card hash. If CardLinkHash is provided, the full Customer object (Code, NameFirst, NameLast, email, PhoneNumber) becomes required.

CustomerobjectbodyOptional

Represents the customer details for a payment.

Customer.CustomerstringbodyRequired

The unique code or identifier for the customer.

CurrencyintegerbodyRequired

The currency code.

ExpiryDatestringbodyRequired

The expiration date and time for this payment request. Format YYYY-MM-DDTHH:mm:ss, Chisinau local time (Europe/Chisinau); must be in the future.

ServicesarraybodyRequired

The list of services included in this payment.

Services[]objectbodyRequired

Represents a service included in the payment request.

Services[].NamestringbodyRequired

The name of the service.

Services[].DescriptionstringbodyRequired

The description of the service.

Services[].AmountintegerbodyRequired

The total amount for this service.

Services[].ProductsarraybodyOptional

(Optional) A list of specific products under this service. If you send products, LineNo, Name, UnitPrice, Quantity, Amount and TotalAmount are required; Code and Description are optional.

Services[].Products[]objectbodyOptional

Represents a single product item within a service.

Services[].Products[].LineNointegerbodyRequired

The line number or position of the product in the list.

Services[].Products[].NamestringbodyRequired

The name of the product.

Services[].Products[].DescriptionstringbodyOptional

(Optional) The description of the product.

Services[].Products[].CodestringbodyOptional

(Optional) Partner product code.

Services[].Products[].UnitPriceintegerbodyRequired

The price per single unit of the product.

Services[].Products[].QuantityintegerbodyRequired

Quantity in hundredths: 100 = 1 pc, 300 = 3 pcs.

Services[].Products[].AmountintegerbodyRequired

The total amount for this quantity in minor units (usually UnitPrice * Quantity / 100).

Services[].Products[].TotalAmountintegerbodyRequired

The final total amount including any taxes or discounts.

MoneyTypestringbodyRequired

Payment methods shown to the customer: "All" — all methods enabled for the merchant; "Card" — card (Visa/Mastercard), Apple Pay, Google Pay; "Paynet" — Paynet wallet; "MIA" — MIA instant payments; "CashInvoice" — cash invoice.

LangstringbodyRequired

UI language for payment page: RO, RU or EN; upper or lower case (EN = en). An unknown value opens the page in English.
