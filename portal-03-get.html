Notification simulator

Method Description

Paynet sends a callback when a payment is paid. Notifications are server-to-server requests to your backend callback URL and must be processed reliably.

  • Paynet sends a callback only when a payment is paid (EventType = PAID). A failed payment produces no callback: the customer is redirected to LinkUrlCancel.
  • Flow is server-to-server, so callback endpoint must be implemented on backend side.
  • Use `Payment.Id` as idempotency key to prevent duplicate business processing. Keys are case-sensitive: `Id`, `ExternalId`.
  • Return HTTP `200` only after signature validation and successful internal processing.

Merchant UX flow

  1. Paste your callback URL into `MerchantSystemUrl (callback URL)`.
  2. Enter the merchant order number (`Order`) you used when creating the payment.
  3. Click `Get` to load transaction state from `GET /api/order/merchant/{'{id}'}`.
  4. Check business status (`paid` / `fail` / `Fail - transaction doesn't exist`).
  5. Click `Send notification` to post callback payload to your URL and verify signature.
  6. CORS is needed only here, because the simulator posts from your browser. Real Paynet notifications come from the Paynet server and do not need CORS; confirm real delivery with a test payment.

Signature validation

Verify every notification before trusting business status. Build `PreparedString` in strict order and compare expected hash with `Header.Hash`.

ExpectedHash = Base64(MD5(PreparedString + SecretKey))
Accept notification only if ExpectedHash === Header.Hash
PreparedString =
EventDate + Eventid + EventType + Payment.Amount + Payment.Customer +
Payment.ExternalId + Payment.Id + Payment.Merchant + Payment.StatusDate

Order is strict. Empty fields must be treated as empty strings.

  1. Parse notification and normalize missing fields to empty strings.
  2. Build `PreparedString` in exact order and append `SecretKey`.
  3. Compute hash and compare with `Header.Hash` (constant-time comparison).
import crypto from 'crypto';

const normalize = (value) => (value === null || value === undefined ? '' : String(value));

function buildPreparedString(notification) {
  return (
    normalize(notification.EventDate) +
    normalize(notification.Eventid) +
    normalize(notification.EventType) +
    normalize(notification.Payment?.Amount) +
    normalize(notification.Payment?.Customer) +
    normalize(notification.Payment?.ExternalId) +
    normalize(notification.Payment?.Id) +
    normalize(notification.Payment?.Merchant) +
    normalize(notification.Payment?.StatusDate)
  );
}

function verifyNotificationHash(notification, secretKey, headerHash) {
  const prepared = buildPreparedString(notification);
  const expected = crypto
    .createHash('md5')
    .update(prepared + secretKey, 'utf8')
    .digest('base64');
  return expected === headerHash;
}
